# Задание 4. Кого бы отправили на вторую линию

Проверка: `python3 src/run_sql.py src/ex04.md` из корня репозитория.
Разметка — в `src/razmetka.csv`. Закоммить оба файла с сообщением `разметка` до того, как начнёшь задание 5.

### 1. Время обработки по темам до апреля

**Ответ:** Темы делятся на три слоя по медиане времени. Долгие: юридический вопрос (59 мин), возврат денег (54), жалоба (53). Средние: техническая проблема (22), оплата и документы (19), прочее (17), NULL (16), без темы (15.5). Быстрые: расписание и посещаемость (8), доступ и пароли (7)(их решают по инструкции за несколько минут).

```sql
SELECT topic,
       COUNT(*) AS n,
       MEDIAN(handle_min) AS med_handle,
       ROUND(AVG(handle_min), 1) AS avg_handle
FROM clean
WHERE period = 'до'
GROUP BY topic
ORDER BY med_handle DESC
```

### 2. Время обработки по теме и приоритету до апреля

**Ответ:** Приоритет двигает время почти везде: возврат денег 71 -> 46 -> 40.5 мин, техническая проблема 33 -> 20 -> 16. Две темы не двигается: доступ и пароли и юридический вопрос. В бесформатных темах (NULL, без темы) чем выше приоритет, тем дольше.

```sql
SELECT topic,
       priority,
       COUNT(*) AS n,
       MEDIAN(handle_min) AS med_handle
FROM clean
WHERE period = 'до'
GROUP BY topic, priority
ORDER BY topic, priority
```

### 3. Возвраты и переоткрытия по темам до апреля

**Ответ:** Возвраты чаще всего идут в техническую проблему и жалобу (по 9.2%, при этом у жалобы ещё и переоткрытие 16%). Формальный ответ там не закрывает проблему. Быстрые темы: доступ и пароли 3.1% переоткрытий, расписание — 4.2%. У возврата денег самые частые переоткрытия (18.5%), но возвратов меньше (6%).

```sql
SELECT topic,
       COUNT(*) AS n,
       ROUND(AVG(reopened), 3) AS share_reopened,
       ROUND(AVG(came_back), 3) AS share_came_back
FROM clean
WHERE period = 'до'
GROUP BY topic
ORDER BY share_came_back DESC
```

### 4. Размер блоков

**Ответ:** До апреля: первая 1642, серая 1433, вторая 136. После: 1744 / 1615 / 190. Не размеченных не осталось.

```sql
SELECT period, blok, COUNT(*) FROM razmetka GROUP BY period, blok
```

## Промежуточный вывод

_Сколько обращений в месяц пришлось бы на вторую линию и на серую зону — в штуках и процентах. По какому признаку проведена граница и каким числом из данных до апреля это подтверждается._

За первые полгода было 3211 обращений  "до", за шесть месяцев было в среднем 535 в месяц. На вторую линию ушло бы 136 обращений, 23 в месяц, это 4.2%. Серая зона — 1433 обращения, 239 в месяц, 44.6%. Остальная половина (51.1%) остаётся на первой линии.

Границу проведена по медиане времени обработки (данные до апреля, когда работали только люди). Dторая линия: всё, что юристы разбирают стабильно около часа независимо от приоритета (58/60/63 мин). Первая: всё, что укладывается в 7–9 мин по инструкции (доступ, пароли, расписание). Между ними серая зона, где время зависит от приоритета и темы (жалобы, возвраты денег, срочные технические).
